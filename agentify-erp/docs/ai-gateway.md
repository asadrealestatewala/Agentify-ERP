# AI gateway, usage ledger and pricing (Stage 1)

* **One door.** `server/src/services/aiGateway.js` is the only code that calls Gemini with Agentify's own (platform) key. It reads the encrypted key from `platform_settings`, calls Google, and writes one `ai_usage` row. Keys never reach the browser or the logs. Calls made with a workspace's own key still use `integrations/ai.js` and keep their current limits (the workspace pays).
* **Ledger.** `ai_usage` gained nullable columns: `feature, user_id, unit, units, usd, usd_pkr, pkr` (added in `services/aiUsage.js`, `db()`; old rows stay valid). Index `idx_ai_usage_feature(feature, at)`. New table `ai_prices(feature, override_usd, updated_by, updated_at)`.
* **Price list.** `services/aiPricing.js`. Order: manual pin, else average of the last 92 days of platform usage once a feature has 10+ successful calls, else a built-in default (USD). Text calls are costed from tokens (owner-entered prices when set in USD, else Gemini 2.5 Flash defaults 0.30 / 2.50 per million).
* **Rupees.** `services/fxRate.js`: live USD to PKR from open.er-api.com (refreshed in the background at most once a day, stored in `fx_rates` with source `live`), a manual override, and a flagged fallback of 280. PKR is display only; providers bill in USD.
* **Not yet (Stage 2+):** the gatekeeper at `gate()` in the gateway (switches, daily limit 300, budgets, video cap, credits), image/video/Azure calls, console screens.

## Stage 2: the gatekeeper (`services/aiGate.js`)
Runs inside the gateway before every platform-key call, in this order (refusal codes in brackets):
1. master kill switch `ai_kill_switch` [`ai_off`]; 2. feature switch from `ai_features_off` [`feature_off`] (both voices share `video_voice`);
3. workspace switch `workspace_ai_settings.ai_enabled` [`tenant_off`]; 4. daily uses per workspace, default 300, override `workspace_ai_settings.platform_daily_limit`, default setting `ai_platform_daily_limit`, resets at midnight UTC [`daily_limit`];
5. monthly budget in USD, setting `ai_budget_usd_month` (falls back to `ai_budget_month` when its label is USD); unset = no cap [`budget_reached`];
6. video budget `ai_video_budget_usd_month` [`video_budget_reached`] and Creative Studio credits (`ai_tenant_credits`: monthly allowance or `ai_default_monthly_credits`, plus this month's top-up; used credits are summed from `ai_usage.credits`) [`no_credits`]. Workspaces on a free trial get 0 credits (the default and plan credits do not apply) unless the console sets a monthly number for that workspace [`trial_no_credits`]; Creative Studio then shows an upgrade prompt.
Refusals are not logged as usage. The call that crosses a budget completes; the next is refused. Workspaces using their own key are governed only by `assertAiAllowed` as before. Console calls (no workspace) skip the workspace checks. New columns: `ai_usage.credits`, `workspace_ai_settings.platform_daily_limit`; new table `ai_tenant_credits`. Values are saved through the existing `PUT /api/platform/ai/controls` (`budget_usd_month`, `video_budget_usd_month`, `platform_daily_limit`, `default_monthly_credits`) and `PUT /api/platform/ai/workspaces/:id` (`platform_daily_limit`).

## Stage 3: the AI page (console > Reports & Analytics > AI, `/platform/ai-usage`)
The former "AI usage & credits" page, extended (same route and menu spot). New component `client/src/pages/platform/AiAgentifyKey.jsx` on top: cost this month (USD and rupees) and per feature, price list with hand-set prices, workspaces (cost, uses today / daily limit, credits with Set and Top up, AI on/off), budget and limits, dollar rate, reported answers (empty until the Report buttons exist), technical details (key status, Azure key and region, model per feature). Server: `services/aiReport.js` (`GET /ai/overview`, `PUT /ai/azure`, `DELETE /ai/azure/key`), `PUT /ai/prices/:feature`, `PUT /ai/fx`, `POST /ai/fx/refresh`, `PUT /ai/workspaces/:id/credits`. Reads need `finance.view`, changes `integrations.manage`. The Azure key is stored encrypted (`azure_speech_key`) and never returned; its connection test and the Hear it voice previews come with the video voices (Stage 4).

## Stage 5: Ask falls back to Gemini (v1.67)
`routes/assistant.js` `POST /ask`: the fast rules run first (`services/assistant.js`, unchanged). Only when the result is `unknown` does `services/askAi.js` call Gemini through the gateway (feature `ask_assistant`, so switches, the daily limit and the budget apply; no credits). The prompt carries the top guide, screen, system-note and release-note text for the question (about 6,000 characters, never support-only `internal` notes, never business data), the last 3 turns the browser sends as `history`, and tells the model to answer only from that material, in the user's language, and to set `found: false` when it cannot. No material means no call. Refusals (switch, limit, budget, unsafe request, rate limit of 10 AI answers per user per minute, provider error) append a short note to the normal reply. `POST /api/assistant/report` writes to `ai_reports` (console AI page). Watch buttons reuse `videoLinks()` and the viewer's role filter.

## Stable Horde as an Ask engine (v1.72)
`services/hordeGateway.js` adds Stable Horde (aihorde.net, a volunteer text network) beside Gemini. Console > AI > "Stable Horde" card: API key (encrypted `stablehorde_api_key`, never returned), Test the connection, optional models (max 5), trusted workers only (default on), and **Ask engine order** (`ask_provider_order`: `horde,gemini` default, `gemini,horde`, `gemini`, `horde`). `services/askAi.js` tries the engines in that order; a provider error moves to the next engine, while a gatekeeper refusal (kill switch, feature off, daily limit, budget) stops all of them. Horde calls pass `assertPlatformAllowed` and write `ai_usage` rows with provider `stablehorde`, cost 0 USD (paid in kudos), estimated token counts; they are excluded from the Gemini token-cost month total.
* **Privacy guard.** The Horde is community run and workers may see prompts. Only our public help-guide text goes as reference, plus the question and last 2 turns after `scrubForHorde()` removes emails, phone/long numbers, key-like strings, links with query strings and the asker's name. No business data is ever sent.
* **Grounding, not training.** Stable Horde cannot be fine-tuned. Ask is "trained" by retrieval: every question is matched against the guides, screen notes, system notes and release notes (`shared/guides.js`, `systemKnowledge.js`), and the model must answer only from them (or say NOT_FOUND). To teach Ask more, add or improve guides/notes.
* **Languages.** The prompt tells the model to reply in the question's language (any it supports). Retrieval is keyword based on English guide text, so questions in non-Latin scripts only find material when an English term (menu name) appears or via the previous turn; a translation step is the next improvement.
* Tests: `server/test/ask-horde.test.js`.
* **Gemini is off for Ask by default** (setting `ask_gemini_enabled`, tick "Allow Gemini for Ask" on the Stable Horde card). While off, Ask never calls Gemini even if its key is set; if the Horde fails, people see a short busy message. Default engine order is `horde,gemini`. Other features (Creative Studio, drafts, translation) keep using Gemini and are not affected. Note: until a Horde key is added, Ask's AI fallback is not available.

## Groq as an Ask engine (v1.76)
`services/groqGateway.js` (OpenAI-style API at api.groq.com). Console > AI > "Groq and Ask engines": key (`groq_api_key`, encrypted, never returned; must start `gsk_`), on/off (`groq_enabled`, on once a key exists), optional chat / picture / speech model overrides (defaults `llama-3.3-70b-versatile`, `meta-llama/llama-4-scout-17b-16e-instruct`, `whisper-large-v3-turbo`), Test the connection, and the **Ask engine order** (`ask_provider_order`, module `askOrder.js`; default `groq,horde,gemini`; engines missing from a stored list are appended). An engine is used only if it is on: Groq = key + switch, Horde = key, Gemini = key + "Allow Gemini for Ask".
* **Chat**: same prompt rules, PII scrubbing (`scrubForHorde`) and NOT_FOUND protocol as the Horde. **429 or any Groq error** is code `provider_error`, so Ask moves to the next engine; gatekeeper refusals stop all engines.
* **Pictures**: `POST /api/assistant/ask` accepts `image` (JPEG/PNG/WebP data URL, under ~1 MB; the browser shrinks it). Only Groq can read it (no fallback; Ask says so). A picture cannot be scrubbed, so the panel warns not to attach client data. Skips the fast data rules.
* **Voice**: `POST /api/assistant/transcribe` (`{audio base64, mime, lang}`) uses Groq Whisper; `GET /api/assistant/capabilities` tells the panel whether to use it (works in the Android app) or the browser's own recogniser. Listen (read aloud) still uses the browser's speech synthesis; Groq text-to-speech is not used.
* **Ledger**: provider `groq`, feature `ask_assistant`, purposes `ask_assistant`, `ask_image`, `ask_voice`; cost recorded as 0 USD (free tier; enter nothing). Groq/Horde rows are excluded from the Gemini price average. Tests: `server/test/ask-groq.test.js`.

## Ask languages and grounding (v1.77)

- Questions in Roman Urdu, Urdu script or Hindi are searched by their English meaning (`shared/help/askTerms.js`, a word list with no AI call). If that finds nothing and Groq is on, Groq turns the question into English keywords once.
- Only help text that covers at least a fifth of the question's meaningful words, and is close to the best match, reaches the engine. No match means no AI call and the normal "not found" reply.
- The prompt names the reply language. If the answer is not in that language (Roman Urdu, Urdu, Arabic, Hindi) it is retried once on the same engine with a stricter instruction.
- Console > AI: the Groq card shows the last failure reason per engine (cleared when the engine next answers) and why Groq is skipped.

## Clean answers and fallbacks (v1.78)

- Reasoning models can print their thinking. `cleanAnswer` (askAi.js) strips `<think>` blocks, keeps text after an `ANSWER:` line and rejects text that reads like notes. A rejected reply moves Ask to the next engine.
- If no engine gives a clean answer (busy, failed or only reasoning) and the question matched a help page, Ask answers from that page: menu path and the guide's own steps, with a short wrapper in the asked language (`templatedAnswer`, engine "guide"). Switch, limit and budget refusals still show their own message.
- The Ask response has `notes`: why an engine was skipped (no key, switched off) or failed. The panel shows them under the answer.

## Which model does what (v1.79)

Console > AI > the Technical card has a "Which model does what" table (`modelMap` in aiReport.js): purpose, engine, model, on/off and the last ledger call. Ask answers show the ranked chain of engines that are ready now; pictures need Groq; voice uses Groq speech-to-text when on, else the browser microphone.

## Test one Ask engine (v1.80)

Console > AI > Groq card > Ask engine order: "Test this engine" (`POST /api/platform/admin/ai/ask-engine/test`, `testAskEngine` in askAi.js) sends the sample question "How do I add an appointment?" with the real guide text to that one engine only. No fallback is used. The result shows the answer, the model the ledger recorded, the time and any error, and a reasoning leak is reported as a failure. The call goes through the normal gateway, so switches, scrubbing and the ledger apply.
